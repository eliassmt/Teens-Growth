TEENUP AI TUTOR SETUP

1. Upload index.html, styles.css, script.js and the api folder to the Teens-Growth GitHub repository.
2. In Vercel: Project -> Settings -> Environment Variables. Add OPENAI_API_KEY with your API key. Apply to Production (and Preview if desired).
3. Optional: add OPENAI_MODEL with the model available to your API account; default is gpt-5.6-luna.
4. Save the variables and redeploy. Vercel environment variables are available to server-side functions, not exposed to browser JavaScript.
5. Open the live site and tap “Ask TEENUP AI”.

Do NOT put the API key in script.js, index.html, or any public GitHub file.
